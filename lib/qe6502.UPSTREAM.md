# qe6502 upstream record

Neo1 carries qe6502 as a pinned Git submodule at `lib/qe6502/`.

- Upstream: <https://github.com/nnqe/qe6502>
- Release: `v1.0.0`
- Commit: `8ae9074203e0a6c46ae687e19194c6a3f4bc1d07`
- License: MIT; see `lib/qe6502/LICENSE`
- Selected: 2026-09-01

The dependency is used only by Neo1 software-CPU runners. The shared machine
does not expose qe6502 types and the physical Neo6502 runner does not link it.
Keep the submodule source unmodified. Neo1-specific instruction aggregation,
machine bus service, reset accounting, and interrupt policy belong in
`src/runners/neo1_soft_runner.c`.

## Selection verification

The selected release's CPU sources are byte-identical to upstream `main` at
`7af43cec306de72459e0b71d6587066876afaa3a`, which was the evaluated checkout.
The two later commits change only the upstream README.

The upstream native WDC functional and extended-opcode tests passed. The
upstream SingleStep harness also passed all 2,540,000 available WDC65C02 cases
from SingleStepTests/65x02 commit
`2f6980a2d95757486c7bee24355c360e40e2a224`. Those cases compare registers,
memory, and visible bus cycles; the WAI (`$CB`) and STP (`$DB`) files contain no
vectors and the other 254 opcode files contain 10,000 cases each.

The unmodified static C core also configured and linked for
`adafruit_fruit_jam` / `rp2350-arm-s` with Pico SDK 2.3.0 and Arm GNU Toolchain
13.3.Rel1.

See `docs/fruit-jam-execution-plan.md` for the candidate comparison, complete
selection evidence, acceptance gate, and integration sequence.
